# 金融数据源选型调研（支撑升级方案 Phase 1 — 选项 A）

> 目的：评估"联网金融数据源（选项 A）"的可行性，重点看 **A 股覆盖、合规性、接入成本**，并据 ReadFlow **铁律 #2（HTTP/数据获取全在 Rust 后端，前端只 `invoke`）** 评估每个源的**技术适配性**（能否被 Rust 直接 HTTP 调用）。
> 调研时间：2026-10-11，价格/政策均来自公开资料，落地前需以官方最新报价为准。
> 本文为调研，非实施方案；选项 A 是否启用仍待用户拍板。

---

## 1. 免费 / 开源数据源

| 源 | A 股覆盖 | 成本 | 技术适配性（Rust 后端） | 备注 |
|---|---|---|---|---|
| **Tushare Pro** | 日线/财务/龙虎榜/北向（分积分档） | 注册免费 120 分；2000 分≈¥200/年解锁财务因子+复权；5000+≈¥500/年 | ✅ **优**：提供 HTTP RESTful API + token，Rust `reqwest` 直接调 | 数据规范、稳定、适合生产；积分不消耗，到档即用 |
| **新浪财经 hq.sinajs.cn** | A 股实时行情（约 15 秒延迟）、指数 | 完全免费，无 key，拼 URL | ✅ **优**：纯 HTTP GET 拼 URL，Rust 直接调，零成本 | 仅行情快照，无财务；商业用途版权边界需注意 |
| **东方财富 open.eastmoney.com** | 行情/财务/新闻公告 | 需开发者账号；免费档约 200 次/分 | ✅ **优**：HTTP API + apikey，Rust 直接调 | 频率限制；实时流需付费 |
| **AkShare** | 最广：行情/财务/龙虎榜/北向/两融/大宗/资金流/宏观 | 完全免费，无需 token | ⚠️ **差**：是 **Python 库**，返回 DataFrame；Rust 不能直接用（除非嵌 Python 或复刻其底层东财/新浪 HTTP 端点——本质变爬虫） | 底层源稳定性不受控，接口随页面改版频繁失效 |
| **BaoStock** | A 股历史日/分钟线、复权、基础财务 | 完全免费，免注册 | ⚠️ **差**：Python SDK，无 HTTP API，Rust 难集成 | 稳定但覆盖窄（无龙虎榜/北向），当日数据晚到 |

**结论**：对 ReadFlow（Rust 后端）而言，**Tushare Pro + 新浪/东财 open API** 是最顺滑的免费组合——三者都有 HTTP 接口，Rust 直接 `reqwest` 调用，无需引入 Python 运行时。AkShare/BaoStock 因 Python 依赖与架构冲突，不推荐作为主源（除非未来愿意嵌 Python）。

## 2. 付费数据源（机构 / 专业个人）

| 源 | 个人年费（约） | 特点 | Rust 适配 |
|---|---|---|---|
| **东方财富 Choice** | 2000–5000 元 | Python SDK + HTTP API，覆盖广，性价比高 | ✅ 配置 apikey 后 Rust 可调用 |
| **同花顺 iFinD** | 3000–8000 元 | A 股最全之一，研报/产业链 | ✅ 有 API |
| **通联数据 DataAPI** | ¥688 | 个人友好、Python API 佳、性价比高 | ✅ |
| **Wind 万得** | 终端 ~3.98 万 + API ~7000/年 | 行业事实标准，数据最全最准 | ⚠️ 需客户端/授权，重 |
| **恒生聚源** | 无个人版 | 纯机构 | ❌ |

**结论**：个人/小团队若愿付费，Choice 个人版或通联 DataAPI 是性价比首选；Wind 过重。付费源质量/稳定性显著优于免费源，但成本上台阶。

## 3. 合规与版权（关键，不可回避）

- **行情版权归属交易所**：上交所/深交所 Level-1/Level-2 行情知识产权归交易所，传播/经营须向 **上证所信息网络有限公司 / 深圳证券信息有限公司** 申请许可（需固定场所、注册资金 50 万+ 等资质）。
- **免费爬虫源（AkShare/新浪/东财网页）风险**：若源本身未获交易所正式授权，用户间接使用可能承担连带责任；**转售/对外发布明确禁止**，商业用途风险高。
- **对 ReadFlow 的定位判断**：ReadFlow 是**本地优先的个人研究情报工具**。若数据仅**本地自用、不转售、不对外发布含行情内容**，个人研究用途下 free-tier 通常可接受；但若"分享报告"包含实时价格/行情快照对外传播，则触及授权边界。
- **最干净的设计**：把 API token 作为**用户本地配置项**（存本地 settings，不出本机），Rust 后端用**用户自己的凭据**拉**用户自己的数据**——合规上最稳，也契合铁律"本地优先/无账户"。

## 4. 与 ReadFlow 架构的适配结论（铁律 #2 视角）

- ✅ **可直接集成（推荐）**：Tushare Pro（HTTP+token）、新浪 hq.sinajs.cn（HTTP 拼 URL）、东方财富 open API（HTTP+apikey）、付费 Choice/通联/通联（HTTP+key）。
- ❌ **架构冲突（不推荐）**：AkShare、BaoStock（Python 库，需嵌 Python 运行时才能用，违背"后端纯 Rust"的简洁性）。
- 🔧 **新模块形态**：Phase 1 的 `src-tauri/src/market.rs` 应通过 `reqwest` 调用上述 HTTP 源，token/apikey 由用户在设置页填入并存本地；抽取/落库/聚合逻辑全在 Rust，前端只 `invoke('fetch_quote', {...})` 渲染。

## 5. 推荐落地路径（供选项 A 决策参考）

**最小可用集（建议 Phase 1 首发）**
1. **主数据源：Tushare Pro**（免费档即可拿日线+基础财务；¥200/年解锁复权+财务因子）。Rust `reqwest` 直调其 HTTP API。
2. **行情快照/价格预警补充：新浪 hq.sinajs.cn**（零成本实时快照，支撑 P2 价格触发预警）。
3. **用户凭据本地化**：设置页新增"数据源配置"（token/apikey 存本地），不硬编码、不出本机。

**可选增强**
- 若用户已有 Choice/Wind 账号 → 配置其 HTTP API key 提升质量（需用户自备凭据）。
- 财报日历：Tushare `trade_cal` / 东财预约披露接口混合。

**明确不做**
- 不引入 AkShare/BaoStock（Python 依赖冲突）。
- 不对外发布/转售任何行情数据（合规底线）。

## 6. 风险与下一步

- **合规**：个人研究自用为主；如未来要做"分享/协作/多端"，需重新评估授权。
- **稳定性**：免费源偶发限频/失效，需加重试+本地缓存（落 `quotes` 表增量更新）。
- **成本**：免费档够 MVP；若需分钟级/实时/L2，再评估付费档。
- **下一步**：若用户确认走选项 A，我将据此把 Phase 1 拆成"具体文件改动清单"的细化实施方案（含 `market.rs` 模块设计、`create_tables` 新表定义、token 本地化存储、重试/缓存策略），再请你确认实施。

## 7. 对升级方案决策项的修订建议

原方案「待确认决策 1：A / B / C」现可收敛为：
- **A（联网 API）可行且技术上最顺**：推荐以 **Tushare Pro + 新浪/东财 open API** 为免费起点，Rust 直调。
- **B（纯 RSS）仍可作为并行层**：RSS 负责"新闻/披露/研报摘要"，API 负责"行情/财务/日历"，二者互补而非互斥——即实质上是 **C（混合）** 最合理。
- 因此建议默认采用 **C 混合**：RSS（现有）+ 行情/财务 API（新增），分阶段上线。
