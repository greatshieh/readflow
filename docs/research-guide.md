# 研究工作台使用指南

研究工作台是 ReadFlow 的核心差异化能力：把「你关心的实体」变成一条自动运转的
信息流水线——**关注实体 → 智能评分 → 事件抽取 → 时间线 → 研究报告 → 实体关系图**。
本文介绍每个环节的用法与联动关系。

## 入口

- 侧栏「···」菜单 → **研究工作台**（弹窗，含全部四个页签）
- 正文栏右下角 **研究事件 FAB**：阅读单篇文章时就地查看/抽取该文的事件
- 侧栏「···」菜单 → **实体关系图**：直接进入主屏全宽关系图

## 前置条件

| 功能 | 要求 |
|---|---|
| 事件抽取 / 报告生成 | 「设置 → AI 设置」中配置好模型、Base URL 与 API Key（任何 OpenAI 兼容接口） |
| 实体评分 | 无需 AI——纯本地字符串匹配，不消耗额度 |
| 报告写入 Obsidian | 「设置 → Obsidian」中配置 vault 路径（未配置时报告通道选「应用内」即可） |

## 推荐工作流

```
① 添加关注实体（实体管理页签）
        ↓ 自动评分，存量文章即时生效
② 阅读时对高分文章做单篇抽取（正文 FAB）
   或建自动化任务做全库批量抽取（设置 → 自动化）
        ↓
③ 时间线页签按时间窗 / 实体筛选浏览事件
        ↓
④ 报告页签生成日报 / 周报（应用内阅读或写入 Obsidian）
        ↓
⑤ 关系图页签 / 主屏查看实体共现网络
```

## 实体管理

关注实体是整条流水线的地基：添加你关心的**公司、人物、产品**等关键词，
系统据此对全部文章智能评分。

- **添加**：输入名称即可；实体在文章中未命中时评分为 0，命中程度越高分越高（0–100）
- **启用 / 禁用**：临时排除某个实体参与评分，不必删除
- **重新评分**：对存量文章重跑评分。增删或启停实体会**自动触发一次评分**，
  让新状态立刻生效
- **评分的意义**：评分是批量事件抽取的上游闸门——只有对实体命中达到阈值的文章
  才会被选中做 AI 抽取，避免把 AI 额度浪费在无关文章上

## 事件抽取与时间线

事件 = 从文章中抽取的结构化事实（谁、做了什么、何时），存入本地时间线。

- **单篇抽取**：阅读文章时点右下角「研究事件」FAB →「提取」。每篇文章标记
  「已尝试抽取」，重复打开不会重复计费，可手动重抽
- **批量抽取**：不逐篇点，而是建一个 `批量事件抽取` 自动化任务（见下文自动化），
  由调度器定期对高评分文章跑全库抽取
- **时间线页签**：按「时间窗口 + 实体」两个维度筛选已抽取的事件，纵向浏览
  「某家公司最近 30 天都发生了什么」

## 研究报告

报告页签顶部是常驻的生成工具条，不依赖自动化任务、随时手动生成：

| 参数 | 选项 | 说明 |
|---|---|---|
| 报告类型 | 日报 / 周报 | 决定聚合口径与默认覆盖天数 |
| 覆盖天数 | 1 / 3 / 7 / 14 / 30 天 | 补报场景可放宽（后端上限 90 天） |
| 输出通道 | 应用内 / Obsidian / 应用内 + Obsidian | 写入 Obsidian 的文件自动带 frontmatter（应用内阅读时会剥离，不影响正文） |

- 报告基于**已抽取的事件**聚合生成——没有任何事件时先生成事件
- Obsidian 写入位置：vault 下的 `ReadFlow` 子目录（可在设置中自定义）
- 历史报告在页签内列表中随时回看

## 实体关系图

展示「哪些实体在同一篇文章中共同出现」的力导向网络，共现越频繁连线越粗。

- **弹窗入口**（研究工作台 → 关系图页签）与**主屏入口**（侧栏「···」→ 实体关系图）
  共享同一份参数与数据，改一处两处同步
- 参数：**时间窗**（统计范围）与**最小共现数**（过滤弱关联，图太密时调高），
  修改即自动重算
- 弹窗右上有**「放大到主屏」**按钮：切到主屏全宽视图（与文章阅读互斥，
  点「返回文章」退出），适合认真浏览大图
- 实体增删 / 评分变化后图会过期，切到图页签时自动重算，不需要手动刷新

## 自动化：让流水线自己跑

「设置 → 自动化」支持三类任务，用 cron 表达式定义节奏：

| 任务类型 | 作用 |
|---|---|
| 批量事件抽取 | 定期对评分达标的文章做 AI 事件抽取（流水线的主力） |
| 日报 | 每天定时生成昨日日报 |
| 周报 | 每周定时生成周报 |

- 任务可随时**停用 / 启用**；停用的任务仍可手动「立即运行」
- 同一任务防重入：正在运行时触发的下一次调度自动跳过
- 运行结果（成功 / 未配置 / 失败及原因）回写在任务行上，出问题先看这里

## 常见问题

**文章评分全是 0？**
检查实体拼写是否与文章正文一致（评分是本地字符串匹配）；刚添加的实体
会自动触发一次评分，若没有，到实体页签手动点「重新评分」。

**批量抽取跑完没有新事件？**
批量抽取只挑「评分达标」的文章；抽查几篇目标文章的评分，必要时提高
实体命中率或直接用单篇抽取验证 AI 配置本身是否可用。

**报告生成报「未配置」？**
报告依赖 AI 配置；写 Obsidian 的报告还需 vault 路径有效。到对应设置页检查。

**关系图是空的？**
图的数据源是「已抽取的事件中的实体共现」，先完成一轮事件抽取；
也可以试着把「最小共现数」调到 1。
